# BDA04 — Caso de uso de IoT: el proyecto STAR de i-DE

**Big Data Analytics** · Profesor D. Juan Manuel Muñoz Domínguez

Análisis de un despliegue de IoT industrial real, de los mayores de Europa: la conversión de
una red de distribución eléctrica convencional en una red instrumentada, medida y operada a
distancia.

## El caso

**Proyecto STAR** (Sistema de Telegestión y Automatización de la Red) de **i-DE Redes
Eléctricas Inteligentes**, la distribuidora del grupo Iberdrola en España.

| Participante | Papel |
|---|---|
| i-DE / Iberdrola Distribución | Promotor y operador: despliegue de contadores, automatización de centros de transformación y explotación de los datos |
| ZIV Automation (Grupo CG) | Suministro de concentradores y equipamiento |
| *(resto de proveedores en el documento)* | |

## Estructura del trabajo

1. **Caso seleccionado y empresas participantes**
2. **El problema**: por qué la red eléctrica necesitaba IoT
3. **Arquitectura IoT desplegada**: contadores inteligentes, concentradores en centros de
   transformación, comunicaciones PLC-PRIME y sistemas centrales
4. **La capa de datos**: del contador al analítico
5. **Analítica avanzada** sobre los datos de campo
6. **Resultados y valoración crítica** — incluyendo lo que el proyecto no resolvió
7. **Glosario** de términos técnicos
8. **Bibliografía y fuentes**
