# GVDM · Gestión y Visualización de Datos Masivos

El bloque más amplio del máster y el que recorre el abanico completo de bases de datos:
por qué el modelo relacional deja de servir cuando los datos crecen, y qué familia de motor
resuelve cada tipo de problema. Casi todas las actividades son de instalación y manejo real
del motor, no de teoría.
