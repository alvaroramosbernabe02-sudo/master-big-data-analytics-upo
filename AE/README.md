# AE · Aplicaciones Empresariales

El bloque aplicado: llevar modelos y agentes a producción y, sobre todo, justificar cuándo
merece la pena. Incluye dos workshops largos en los que se construye un sistema completo
—un agente de atención al cliente y un conjunto de agentes analíticos— y un despliegue
real de un LLM en la nube.
