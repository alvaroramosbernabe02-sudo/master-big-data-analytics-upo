# PT · Plataformas Tecnológicas

El bloque de infraestructura: cómo se ingiere, se procesa y se sirve el dato cuando ya no
cabe en una máquina. Google Cloud es el hilo conductor de casi todas las actividades, con
Kafka para la ingesta y Databricks para el procesamiento en streaming.
